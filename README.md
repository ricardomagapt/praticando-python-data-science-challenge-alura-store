# 🛍️ Alura Store - Análise de Desempenho das Lojas

Este projeto tem como objetivo analisar o desempenho das quatro lojas do e-commerce fictício **Alura Store**. O Sr. João, proprietário da rede, deseja vender uma das lojas para investir em um novo negócio. A análise dos dados ajudará a tomar essa decisão de forma **estratégica e baseada em dados reais**.

---

## 🎯 Objetivo

Identificar **qual das quatro lojas** possui o pior desempenho com base nas seguintes métricas:

- Faturamento total
- Categorias mais vendidas
- Média de avaliação dos clientes
- Produtos mais e menos vendidos
- Custo médio do frete

Ao final, uma **recomendação clara** é feita ao Sr. João sobre qual loja vender.
